For task3, I first cleared the screen with a request to the "clear" server with call type "std_srvs/srvs/Empty" as a service call. Then, similarlly, to change the color of the lines the turtle makes we make a request to the "turtle1/set_pen" server with call type "turtlesim/srv/SetPen". An argument isn't necessary for this call becuase the default behavior is to set it the RGB to {0, 0, 0}. I then pressed the up arrow key on the teleop terminal to move it one unit forward, followed by a rotation call. The rotation call is done with an action send_goal to trigger the "rotate absolute" action. setting the theta to be in intervals of pi/2 rotates the turtle by 90 degrees counterclockwise. Doing this move and rotate 4 times results in a black square drawn by the turtle.
