To draw a black square with turtlesim, I first changed the pen to black using the set_pen serivce with the "{r: 0.0, g: 0.0, b: 0.0, width: 3}" argument.  I then moved the turtle in an increment of 2.0 using the cmd_vel topic with the argument "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}".  To rotate 90 degrees, I ran the rotate_absolute action with the argument "{theta: 1.57}".  Then, the topic and action were called 3 more times, with the action theta increasing by 1.57 for each call.
